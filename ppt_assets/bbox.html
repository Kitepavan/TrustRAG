KNOWLEDGE POISONING BASELINE RAG PIPELINE Upload document ✕ Chunk text (512 / 64) ✕ Embed (768-d vectors) ✕ Store in vector DB ✕ top-K similarity search ✕ An attacker uploads a document semantically similar to a real policy but with inverted guidance — “Passwords are no longer required.” Retrieval surfaces it and the LLM answers from it. INDIRECT PROMPT INJECTION Retrieved text embeds overrides — “IGNORE ALL PREVIOUS INSTRUCTIONS” — hijacking the model from inside the context window, even when the model itself is functioning perfectly. TAMPERING & UNAUTHORIZED ACCESS Send context to LLM ✕ Modified files index undetected, and any employee can retrieve HR- or IT-confidential documents. A valid-looking answer may come from tampered or unauthorized sources. No verification at any stage Relevance alone cannot guarantee safety — retrieval must also prove authenticity, authorization, and integrity. THE SOLUTION Trust Beyond Relevance TrustRAG evaluates every retrieval candidate on security as rigorously as on semantic similarity — before a single token reaches the LLM. OUTLOOK Advantages & Future Scope A D VA N TA G E S FUTURE SCOPE Security shifted left of the LLM — malicious content is blocked before generation, not after. ML classifiers for injection & poisoning, replacing heuristic regex pattern rules. Defense in depth — four independent checkpoints; no single point of trust. Enterprise PKI with HSM-backed keys, rotation, and delegated signing. Tamper-evident audit trail — Ed25519 + SHA-256 + atomic provenance log. Document versioning with signed, chained provenance records. Least-privilege retrieval — RBAC clearance enforced per chunk at query time. PII scrubbing and differential privacy for confidential corpora. Data sovereignty — local 768-d embeddings; document text never leaves the enterprise. Async streaming ingestion and corpus-scale evaluation (RAGAS-style metrics). Fail-closed by design — unverified or tampered content is quarantined, never silently used. Attribute-based access control (ABAC) and policy-as-code enforcement. TrustRAG makes retrieval a security decision — not just a similarity search.
